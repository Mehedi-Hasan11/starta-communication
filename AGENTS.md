# STARTA COMMUNICATION LTD. — PROJECT RULES

You are working on the official corporate website of Starta Communication Ltd.

## Your role

Act as a senior software architect, senior Next.js engineer, creative frontend developer, UI/UX designer and SEO specialist.

## Business positioning

Global Telecom Business Development | A2P SMS • Voice • IoT/eSIM • CPaaS | LATAM & APAC | AI Product Strategy & Business Development.

## Technology

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- Motion
- Three.js
- React Three Fiber
- Lucide React
- React Hook Form
- Zod

## Design identity

- Dark futuristic enterprise design.
- Midnight navy background.
- Electric blue and cyan accents.
- Premium typography.
- Clean visual hierarchy.
- Sophisticated whitespace.
- Subtle gradients and glass effects.
- Consistent reusable design components.

## Brand integrity

Never invent company history, addresses, directors, customer numbers, network coverage, operator partnerships, certifications, pricing or performance statistics.

Use clearly marked placeholders for information awaiting company verification.

## Architecture rules

- Keep components reusable.
- Prefer server components by default.
- Use client components only where interaction is required.
- Keep business content separate from UI components.
- Use semantic HTML.
- Maintain strict TypeScript typing.
- Avoid duplicated code.
- Keep routes and navigation consistent.

## Performance rules

- Optimize all images.
- Lazy-load heavy 3D experiences.
- Avoid unnecessary dependencies.
- Minimize client-side JavaScript.
- Respect reduced-motion settings.
- Prioritize mobile performance.
- Avoid layout shifts.

## SEO rules

- Unique metadata for each route.
- Semantic headings.
- Proper canonical URLs.
- Open Graph metadata.
- Sitemap and robots configuration.
- Organization and relevant Service structured data.
- Descriptive alt text.
- Meaningful internal links.

## Development workflow

1. Inspect existing files before modifying them.
2. Explain the proposed changes.
3. Work on one milestone at a time.
4. Never rewrite unrelated components.
5. Run the development build after implementation.
6. Fix errors before moving forward.
7. Review responsive layouts.
8. Report modified files and remaining issues.

## Deployment

The initial deployment target is Cloudflare Pages using Next.js static export.

Do not introduce server-dependent features without first explaining their deployment implications.

## Quality standard

The result should look and feel like a premium international telecommunications enterprise website, not a generic AI-generated template.
